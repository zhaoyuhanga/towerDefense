## Elevator Pitch

> 这是一款**迷宫建造型塔防游戏**，你用障碍方块设计怪物的行进路线，用拖拽合星的方式培养防御塔，在一波波永无止境的进攻中验证你的布局智慧。不是在推关——你是在建造一座怪物注定死去的迷宫。

## Core Fantasy

> **你是怪物迷宫的建造者。** 每放下一块障碍方块，你就重新定义了一次怪物的命运。它们走的每一步都在你的计算之内，每一次转弯都让它们多挨一轮炮火。当怪物们在你设计的死亡走廊里来回折返、被你的三星炮塔收割殆尽时——那种"一切都在我掌控之中"的满足感，就是这款游戏的全部。

这不是一个关于反应速度的幻想。这是关于**规划、预见和设计**的幻想。

---

## Unique Hook

> 传统塔防给你一张有固定路线的地图。这款游戏把地图交给你自己设计——**方块画路线，合星养防御塔，不同星级的塔做不同的事**。

And also：无限模式不是"打完了再加几关"——它就是游戏的全部。你的最高波数就是你的勋章。

## Player Experience Analysis (MDA Framework)

### Target Aesthetics（玩家感受到什么）

| Aesthetic | Priority | How We Deliver It |
| ---- | ---- | ---- |
| **Challenge**（挑战） | 1 | 无限波次难度递增，每一波测试你布局的上限 |
| **Expression**（表达） | 2 | 每个玩家的迷官方块布局独一无二，没有"标准答案" |
| **Fantasy**（幻想） | 3 | 你是地下城建筑师——怪物在你设计的迷宫中走向死亡 |
| **Submission**（放松） | 4 | 筑城阶段无时间压力，可以仔细思考每一步 |
| **Sensation**（感官） | 5 | 合星特效、塔攻击动画、怪物成群倒下的视觉反馈 |
| **Narrative**（叙事） | N/A | 无剧情 |
| **Fellowship**（社交） | N/A | 纯单机，本地排行榜即可 |
| **Discovery**（探索） | 6 | 不同方块+塔组合的策略探索 |

### Key Dynamics（会自然涌现的玩家行为）

- 玩家会反复尝试不同的迷官方块布局，比较同一波次的通过效率
- 玩家会实验塔的类型搭配和星级组合，寻找"最优解"
- 玩家会在低星功能塔和高星输出塔之间做取舍——棋盘空间是有限的
- 玩家会主动分享自己的"死亡迷宫"布局截图和高波数纪录

### Core Mechanics（核心系统）

1. **障碍方块系统**：在棋盘网格上放置方块，改变怪物寻路，拉长行进距离
2. **合星升级系统**：拖拽两个同星塔合成更高星级，攻击力翻倍，解锁新攻击模式
3. **无限波次系统**：难度持续递增，怪物属性、组合、词缀随波次变化
4. **应急技能系统**：战斗中有限使用（冰冻、减速、维修），次数靠准备阶段积累
5. **回合准备阶段**：每波之间有充足时间思考、调整布局、合成塔

## Player Motivation Profile

### Primary Psychological Needs Served（SDT / PENS 模型）

| Need | How This Game Satisfies It | Strength |
| ---- | ---- | ---- |
| **Autonomy**（自主感） | 玩家自己设计路线、选择塔类型和位置、决定合成时机——几乎每个决策都是玩家自己的 | **Core** |
| **Competence**（胜任感） | 波数越高 = 布局越成功；看着自己设计的防线高效收割怪物，是对能力的直接证明 | **Core** |
| **Relatedness**（关联感） | 纯单机，无多人互动。本地排行榜提供间接的"比较" | **Minimal** |

### Player Type Appeal（Bartle 分类）

- [x] **Achievers**（成就者）— 核心受众。最高波数、最优布局、合星到满星的成就感
- [x] **Explorers**（探索者）— 次要受众。探索不同方块布局和塔搭配的策略空间
- [ ] **Socializers**（社交者）— 不适合。无多人交互
- [x] **Killers/Competitors**（竞争者）— 部分适合。本地排行榜驱动的"比自己/比朋友更强"

### Flow State Design（心流设计）

- **上手曲线**：前三波作为教程——第一波只有一种塔，教方块放置；第二波教合星；第三波教应急技能
- **难度缩放**：分阶段递增——前 10 波线性增长（建立信心）→ 10-25 波非线性加速 → 25 波后引入词缀和特殊怪物（保持新鲜感）
- **反馈清晰度**：每波的统计面板（击杀数、路径长度、塔输出占比），让你清楚知道哪里做对了
- **失败恢复**：波次结束立即可以调整布局重来，无惩罚。失败是"上一局的布局不够好"，不是"你操作慢了"

## Core Loop

### Moment-to-Moment（30秒）
玩家在准备阶段**查看下一波怪物预览 → 决定放方块还是合成塔 → 执行操作 → 按下开始**。核心操作是"放方块"和"拖拽合星"，两种操作都有直接的视觉/手感反馈。

### Short-Term（5-15分钟）
一波完整的循环：**准备（1-2分钟）→ 战斗观战（1-2分钟）→ 结算 → 准备下一波**。这个循环中"再撑一波"的心理驱动非常强——怪物就差一点就突破防线了，调整一下就能过。

### Session-Level（30-120分钟）
一局游戏持续到防线崩溃。典型一局 30-45 分钟，玩家会经历：建立基础布局 → 遇到第一次瓶颈 → 大调整 → 进入"自动化流畅期" → 被更强的怪物组合突破 → 游戏结束，查看统计和最高波数。

### Long-Term Progression
- **局内成长**：塔的合星升级、金币积累、方块数量扩充
- **局间成长**：目前纯靠玩家自身策略水平的提升（无局外养成，保持纯粹的策略竞技性）—— 未来可考虑解锁新塔类型/方块皮肤

### Retention Hooks
- **Mastery**（精通）：最强驱动力——"下次我换个布局一定能撑更多波"
- **Investment**（投入）：自己设计的迷宫有情感所有权，"这是我的作品"
- **Curiosity**（好奇）：高波数的怪物词缀组合是什么？我能撑到看到它吗？

## Game Pillars

> 审查模式：Lean — CD-PILLARS 和 AD-CONCEPT-VISUAL 已跳过。

### Pillar 1：路线即武器（The Path Is Your Weapon）

玩家的首要武器不是塔，而是方块。用方块扭曲怪物路线，把它们引入你设计的死亡走廊。

*Design test*：如果塔能直接秒杀怪物 vs 方块能让怪物多绕 3 圈——这个支柱说：**选方块**。

### Pillar 2：每一波都是考卷（Every Wave Is a Test）

不是在"推关"，是在参加一场难度永无止境的考试。每一波都是对你布局设计的一次检验。

*Design test*：如果加"自动战斗跳过"功能 vs 必须看完每一波——这个支柱说：**必须看完**。

### Pillar 3：低星不废，高星不无敌（Stars Define Role, Not Power）

一星塔有减速，三星塔有爆发。不是"越高星越好"，而是"不同星级的塔解决不同问题"。

*Design test*：如果三星塔全面碾压一星塔 vs 一星塔有不可替代的功能——这个支柱说：**一星必须有独特价值**。

### Pillar 4：你造，你观，你调（Build, Watch, Adapt）

筑城阶段深思熟虑，战斗阶段捏着应急手段。节奏是"思考 > 观看 > 微调"，不是"手忙脚乱"。

*Design test*：如果加实时微操（RTS 式框选）vs 保持纯策略节奏——这个支柱说：**不要实时微操**。

### Anti-Pillars（这游戏不做什么）

- **不做关卡**：没有"第 1 关 → 第 2 关 → 通关"。只有一张无限地图，挑战来自怪物组合和数值变化
- **不做实时微操**：没有 RTS 式的框选、战斗中快速换位。准备阶段是思考时间，战斗阶段是验收时间
- **不做多人在线**：纯单机离线。可以有本地排行榜（最高波数），但绝不做联机匹配/合作/PvP
- **不做剧情**：没有对话、没有过场、没有世界观文本。游戏体验来自机制本身

## Technical Considerations

| Consideration | Assessment |
| ---- | ---- |
| **Recommended Engine** | **Godot 4.6** — 原生 2D 引擎（TileMap + Grid 系统直接适配棋盘布局），GDScript 上手快，Windows/Mac 一键导出，MIT 协议零成本 |
| **Key Technical Challenges** | 怪物寻路在动态障碍方块下的实时重计算（A* + 增量更新）；合星拖拽的 UI 手感在桌面端的实现；无限模式的难度曲线平衡 |
| **Art Style** | 2D 俯视/等距视角。干净、可读性强的风格——棋盘格清晰，怪物和塔有明确视觉区分 |
| **Art Pipeline Complexity** | 低-中（2D 精灵图，无需复杂 3D 管线） |
| **Audio Needs** | 中等 — 塔攻击音效、怪物死亡音效、UI 点击/合成音效、背景环境音。不需要自适应音乐，一首好的循环背景即可 |
| **Networking** | 无网络需求。纯离线 |
| **Content Volume** | MVP：1 张地图 + 3 塔种 × 3 星 + 1 种方块 + 20+ 怪物类型变体 |
| **Procedural Systems** | 怪物波次组合可由规则系统生成（按波数选怪物模板 + 词缀），无需真正的程序化地图 |

## Risks and Open Questions

### Design Risks
- **合星系统在桌面端的"手感"不如触屏**：拖拽合成在手机上天然，桌面端需要补偿设计（右键菜单、双击合成）。缓解：双操作模式
- **无限模式的难度曲线难调**：太陡 → 挫败感强；太缓 → 无聊。缓解：分阶段递增（线性→指数→词缀），每 25 波加一种新变量
- **低星塔的价值在后期被稀释**：如果高星塔 DPS 碾压，低星塔的功能性优势必须足够强。缓解：低星塔的减速/控制效果用**固定百分比**而非数值，不受星级影响

### Technical Risks
- **动态寻路性能**：每次放方块都需要重算怪物路径，后期方块数量增多时计算量上升。缓解：缓存已计算路径段，只在方块影响区域内增量更新
- **合星 UI 实现**：拖拽 + 塔位占用 + 撤销的交互状态机比较复杂。缓解：早期用简单交互原型验证，不追求一步到位

### Market Risks
- **塔防品类认知固化**：玩家可能先入为主认为这是"又一个手机塔防"。缓解：Steam 商店页重点强调 Mazing 自由度和合星深度，用 GIF 展示"一张地图上玩家自己设计的迷宫"
- **定价敏感**：桌面塔防的价格锚点较低（Bloons TD 6 本体 ¥22）。缓解：MVP 阶段验证核心乐趣后再定价格策略

### Scope Risks
- **怪物种类和词缀数量**：无限模式需要足够的怪物变体来维持新鲜感。缓解：用组合规则（怪物模板 × 词缀 × 数值缩放）代替逐一手工设计

### Open Questions
- 怪物寻路在大量方块放置后性能如何？→ 用 Godot AStarGrid2D 做一个 20×20 的棋盘原型，测 100+ 方块时的寻路耗时
- 合星系统是纯拖拽还是加键盘辅助？→ 先做拖拽原型，测试 5 个人看反馈
- 要不要局外养成（解锁新塔/方块）？→ 先做纯局内版本（保持策略纯粹性），根据测试反馈再决定

## MVP Definition

**核心假设**：玩家对"自己设计怪物行进路线 + 拖拽合星升级塔"的核心循环会感到满足，愿意反复游玩以追求更高波数。

**MVP 包含**：
1. 一张 20×15 的可编辑棋盘地图
2. 障碍方块系统（放置/移除，影响怪物寻路）
3. 3 种防御塔（炮塔/冰塔/箭塔），每种 3 个星级，不同星级不同功能定位
4. 拖拽合星升级（两个同星塔拖到一起 = 高一级）
5. 无限波次模式（怪物属性随波数递增，25 波后引入词缀）
6. 2 种应急技能（冰冻减速、紧急维修），战斗中使用次数有限
7. 本地最高波数记录
8. 基础 UI（准备按钮、波数显示、金币/资源栏、技能按钮）

**MVP 明确不包含**：
- 多张地图/主题皮肤
- 局外养成/解锁系统
- 成就系统
- 排行榜/分数上传
- 音效（可在 MVP 后期加入基础音效）
- 怪物出场动画/高级视觉特效

### Scope Tiers

| Tier | Content | Features | Timeline |
| ---- | ---- | ---- | ---- |
| **MVP** | 1 地图、3 塔种×3 星、1 种方块、基础怪物 | 核心循环（方块+合星+无限波+技能） | 2-3 月 |
| **V1.0** | 5 塔种×3 星、怪物词缀系统、完整 UI | MVP + 更多塔种、难度曲线精细调校、音效 | 4-5 月 |
| **远期** | 多地图/主题、成就、更多应急技能 | V1.0 + 视觉多样性 + 社区功能 | 6+ 月 |
