# 准备阶段系统 (Preparation Phase System)

> **Status**: In Design | **Implements Pillar**: Pillar 4 — 你造你观你调（"造"的时间窗口）

## Overview

准备阶段系统管理每波之间的"筑城时间"——这是玩家放置方块、购买/放置/合星塔、预览下一波怪物的唯一时间窗口。玩家按下"开始"按钮后进入战斗阶段；战斗结束后自动回到准备阶段。准备阶段是 Pillar 4 "你造"的物理载体——没有时间压力，只有规划和分析。

## Detailed Design

### Core Rules

1. **进入准备阶段**：游戏开始 → 准备阶段。每波战斗结束 → 准备阶段。
2. **可用操作**：放置方块、放置/出售/合星塔、查看塔信息。所有建造阶段输入（见输入处理 GDD）。
3. **不可用操作**：应急技能（战斗阶段专属）。
4. **下一波预览**：准备阶段显示下一波怪物信息——类型、数量、是否有词缀/Boss。
5. **开始波次**：玩家点击"开始"按钮 → 离开准备阶段 → 进入战斗阶段。

### States

`PREP` ↔ `BATTLE` —— 由玩家点击"开始"和波次结束自动切换。

### Interactions

| 接口 | 签名 | 调用者 |
|------|------|--------|
| 阶段切换 | `set_phase(phase: Phase)` | 波次生成、输入处理 |
| 阶段变更信号 | `phase_changed(old, new)` | 所有系统（门控操作） |

## Dependencies

| 上游 | 关系 |
|------|------|
| 输入处理 | Hard — 阶段门控 |
| 障碍方块、防御塔、合星升级 | Hard — 操作窗口 |
| 经济系统 | Hard — 出售/购买 |

| 下游 | 关系 |
|------|------|
| 波次生成 | Hard — 触发战斗开始 |
| HUD/UI | Hard — 显示阶段+下一波预览 |

## Edge Cases

- 阶段切换期间点击 → 输入丢弃（输入处理 GDD Edge Cases）
- 玩家在准备阶段不做任何操作直接开始 → 允许（虽然不明智）
- 所有塔/方块被卖光 → 允许——玩家可以选择重置策略

## Acceptance Criteria

- **GIVEN** 游戏开始，**WHEN** 初始化完成，**THEN** 进入 PREP 阶段
- **GIVEN** PREP 阶段，**WHEN** 点击"开始"，**THEN** 切换到 BATTLE，`phase_changed` 信号发射
- **GIVEN** BATTLE 阶段，**WHEN** 波次结束，**THEN** 自动切换到 PREP
