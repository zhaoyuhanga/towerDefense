## Section 1: Visual Identity Statement

### One-Line Visual Rule

> **路线是画面中唯一不可被弱化的视觉元素。**

任何视觉决策——特效密度、UI 覆盖面积、动画炫目程度——都必须先经过这句话的过滤：**它会不会挡住或弱化路线？**

"路线"在此文档中的定义：**网格 + 障碍方块 + 怪物路径线**的三合一整体。玩家需要同时看到三者才能理解布局状态。

这条法则直接服务于 Pillar 1（路线即武器），同时保障了 Pillar 2（每一波都是考卷）所需要的"验收可读性"。

### Supporting Visual Principles

#### Principle 1: 网格即舞台（The Grid Is the Stage）
**服务于 Pillar 1 — 路线即武器**

棋盘网格是玩家所有空间决策的载体，是画面中最稳定的视觉锚点。所有游戏元素（方块、塔、怪物、特效）坐落在网格**之上**，网格不被元素覆盖。网格线在建造和战斗两个阶段都必须保持可见。

> **设计测试**：当战斗特效密度上升、网格线开始被粒子遮挡时 → 降低特效层透明度，让网格线透出。特效的华丽度永远让位于网格的可读性。

#### Principle 2: 形状定义功能，点缀定义星级（Shape Defines Function, Accent Defines Star）
**服务于 Pillar 3 — 低星不废，高星不无敌**

塔的视觉设计分两个独立维度：
- **永久维度**（塔类型 → 轮廓/形状传达）：炮塔方形、冰塔圆形、箭塔三角形——类型一看轮廓就知道
- **可变维度**（星级 → 点缀色、光晕数量、动画节奏）：星级用点缀表达，不用体积表达

高星塔**不得**通过更大的模型、更密的粒子或更炫的光效来彰显自己。如果一星塔显得"平淡"，那是点缀细节不够精致——用更考究的点缀设计，而非更大的体积来修正。

> **设计测试**：当三星塔和一星塔放在一起，三星塔"看起来更强"时 → 改变点缀色/光晕数量，不放大模型体积。

#### Principle 3: 建造冷静，观看紧张（Build Cool, Watch Tense）
**服务于 Pillar 4 — 你造，你观，你调**

建造阶段和战斗阶段使用两套可区分的视觉氛围，帮助玩家在"思考模式"和"验收模式"之间做认知切换：

- **建造阶段**：低饱和度、冷色基底、高对比度。服务于分析和规划。
- **战斗阶段**：暖色从 UI 边框渗入，警示色出现。棋盘网格本身的基底色调**不变**——变化只发生在 UI 框架、背景氛围和特效层。

> **设计测试**：当需要在战斗阶段传达"防线即将崩溃"的紧张感时 → 用 UI 边框脉动红闪 + 怪物路径末端高亮警示，不在棋盘上铺全屏红色滤镜。玩家在紧张时更需要看清路线来使用应急技能。

### Pillar → Principle Mapping

| 支柱 | 核心视觉需求 | 对应原则 |
|------|-------------|---------|
| P1: 路线即武器 | 路线必须是画面焦点 | 原则 1: 网格即舞台 |
| P2: 每一波都是考卷 | 验收结果必须可读 | 法则本身（路线不可弱化） |
| P3: 低星不废 | 星级 ≠ 视觉强度 | 原则 2: 形状/点缀分离 |
| P4: 你造你观你调 | 两种认知模式 | 原则 3: 建造冷/战斗暖 |

## Section 2: Mood & Atmosphere

### 设计锚点

1. 棋盘网格基底色温恒定（原则 3）。情绪变化只通过 UI 框架、背景氛围层、特效层传达。
2. 路线始终可见（一句话法则）。任何氛围效果不得遮挡或弱化路线/网格。

### 2.1 菜单/准备（Menu / Preparation）

- **主要情绪目标**：蓄势 — 战前的沉静期待
- **光照特征**：深蓝/靛蓝基底（~6500K-8000K），单一暖色点光源来自"开始"按钮或标题文字。对比度高，中心向外扩散。
- **氛围描述**：静谧、专注、仪式感、蓄势待发
- **能量水平**：沉思 / 克制
- **承载情绪的具体视觉元素**：网格在深色背景中以低透明度（~15-25%）隐约浮现，如同在暗室中俯视发光的沙盘地图。玩家看到的是一个"等待被填满的舞台"。

### 2.2 建造阶段（Build Phase）

- **主要情绪目标**：冷静分析
- **光照特征**：冷灰蓝基底（石板灰 + 微量蓝偏移），完全无暖色渗入。全画面均匀高对比——服务于分析可读性，无方向性强光。
- **氛围描述**：清晰、克制、理性、安静、专注
- **能量水平**：克制 / 沉思
- **承载情绪的具体视觉元素**：网格线在此阶段以最高可见度呈现（~60-80%），可放置区域有冷白色半透明高亮提示。光标悬浮时出现冷白色预览方块——颜色精确、边界清晰、无光晕扩散。整个画面传达的信号是："这里没有意外，一切都在你的计算之中。"

### 2.3 战斗阶段（Battle Phase）

- **主要情绪目标**：逐渐攀升的紧张
- **光照特征**：棋盘基底色温不变（保持冷灰）；UI 边框从冷色 → 暖橙 → 危险红渐变渗入；特效层使用暖色高光。暗部随波次加深，亮部更刺目，但路线/网格始终在中间调保持可读。
- **氛围描述**：紧张、专注、动态、逐渐压迫
- **能量水平**：紧张 / 攀升
- **承载情绪的具体视觉元素**：UI 边框脉动暖色光晕——橙色随怪物接近终点逐渐加深为红色，频率随怪物剩余血量降低而加快。如同仪表盘上的警示灯。怪物路径沿途留下短暂的暖色残影轨迹，如烧红的铁轨——路线本身仍是冷色，但"被走过的路"留下了温度。

### 2.4a 波次胜利（Wave Victory → 结算）

- **主要情绪目标**：释放与满足
- **光照特征**：战斗暖色快速褪去（~0.3-0.5秒），冷色确认光在路线终点亮起（蓝白/金白微光）。全局短暂去饱和 → 结算数字高对比弹出。焦点从全屏收拢至终点/结算区域。
- **氛围描述**：畅快、确认、满足、短暂的静止
- **能量水平**：峰值释放 → 快速回落（从紧张到放松的"呼气时刻"）
- **承载情绪的具体视觉元素**：画面短暂暗角聚拢，终点亮起冷色确认光——如同"验收通过"的视觉戳记。路线从起点到终点的完整路径短暂高亮（~1秒），让玩家看见自己设计的路线完成了使命。

### 2.4b 危机/防线突破（Crisis / Breach）

- **主要情绪目标**：警报与紧急
- **光照特征**：突破点红色脉动警示（高饱和红，~2Hz），周围区域快速去饱和——精准红色指向，非全屏滤镜。突破点为画面最亮/最饱和区域。
- **氛围描述**：警报、紧迫、失控、审判
- **能量水平**：骤升（警报瞬间）→ 悬停（结算判断）
- **承载情绪的具体视觉元素**：红色集中在突破点本身 + 该段路线高亮 + UI 边框急速红闪。棋盘不铺全屏红色滤镜——玩家在危机时需要看清剩余路线来理解"哪里出了问题"。结算时被突破的路线段以红色残影标记在网格上，如同伤疤。

### 情绪弧线总览

| 状态 | 情绪 | 色温 | 能量 | 路线可见度 |
|------|------|------|------|-----------|
| 菜单/准备 | 蓄势 | 深蓝/靛蓝 | 沉思克制 | ~20% |
| 建造阶段 | 冷静分析 | 冷灰蓝 | 克制专注 | ~70% |
| 战斗阶段 | 攀升紧张 | 冷基底+暖边缘 | 紧张攀升 | ~60% |
| 波次胜利 | 释放满足 | 冷色回归+确认光 | 峰值→回落 | 短暂高亮确认 |
| 危机突破 | 警报紧急 | 精准红色警示 | 骤升→悬停 | 高可见+红残影 |

## Section 3: Shape Language

### 3.1 几何词汇

**核心论断**：这是一个关于几何构建的游戏。方形的世界被圆形和三角形点缀，被有机曲线入侵。

| 形状 | 语义 | 代表元素 | 情感 |
|------|------|---------|------|
| **方形** | 秩序、建造、可控 | 网格单元格、障碍方块、炮塔、UI 面板 | 稳定、理性、"这是我的领地" |
| **圆形** | 辅助、范围、流动 | 冰塔、资源指示器、怪物入口/出口 | 包容、保护、"这里有支援" |
| **三角形** | 方向、精准、锐利 | 箭塔、星级光点、攻击方向指示 | 精确、"看这里 / 打这里" |
| **有机曲线** | 混沌、入侵 | 怪物剪影 | 不安、威胁、"必须消灭" |

**支配层级**：方形 >> 圆形 > 三角形。有机曲线数量随波次增长，但永远不超过建造元素总和。

### 3.2 元素形状规则

#### 棋盘网格线
- 正交直线，0°/90° 交叉，1-2px 均匀线宽（1080p）
- 实线无虚线无渐变，转角严格 90° 无圆角
- 视觉风格：坐标纸 / 蓝图——网格是测量工具，不是装饰
- 连接：原则 1（网格即舞台）

#### 障碍方块
- 完美正方形，与网格单元格对齐
- 锐利 90° 边角，无斜面/圆角/倒角
- 扁平但实体——高对比度边缘 + 微妙投影
- 完全不透明——必须读作"不可穿越"
- 方块在网格之上，但网格线在方块周围仍可见——方块是"棋盘上的棋子"，不是"挖掉的格子"
- 连接：支柱 1（路线即武器）

#### 三种防御塔 — 轮廓
- **炮塔 = 纯方形**（发射爆炸弹）
- **冰塔 = 纯圆形**（范围减速）
- **箭塔 = 纯三角形**（单体精准）
- 严格单一形状，无混合——在 20×15 棋盘的小渲染尺寸（~32-64px）下，纯几何轮廓辨识度最高
- 连接：原则 2（形状定义功能）

#### 星级点缀
- 三角形光点：1 星 = 无，2 星 = 2 个三角，3 星 = 3 个三角 + 微弱轮廓光晕
- 三角形延续全局"精确/指示"语义
- 星级点缀改变光点数量和光晕强度——绝不改变塔的轮廓或体积
- 连接：原则 2 + 支柱 3（低星不废，高星不无敌）

#### 怪物
- 100% 有机曲线构成——无直线、无尖角
- 约束在 1 格内，形状不填满方格——边缘留有呼吸空间
- 每种怪物类型有独特剪影（圆形、椭圆形、不规则形）
- 核心视觉张力："你建造的几何秩序 vs 试图摧毁它的混沌"
- 连接：支柱 2（怪物是秩序的"考题"）

### 3.3 UI 形状语法

- **延续世界几何**：UI 面板/按钮使用尖角矩形，与棋盘网格的刚性几何统一
- 面板/容器：矩形，尖角，无圆角
- 按钮：方形或微矩形，尖角
- 进度条/资源条：细长方形，平头
- 图标：几何简化——延续方形/圆形/三角形的全局语义
- 战斗阶段：形状不变，颜色变——边框从冷灰切换为暖色
- **唯一例外**：怪物血条使用微圆角——附着在有机实体上的 UI 元素
- 连接：原则 3（建造冷/战斗暖）

### 3.4 主角形状 vs 配角形状

| 层级 | 元素 | 形状策略 | 吸引/退后手段 |
|------|------|---------|-------------|
| **主角** | 怪物路径线 | 流动有机线条 | 暖色、高对比度、动态、在冷色方网格上"格格不入" |
| **主角** | 活跃塔 | 清晰几何轮廓 + 星级光晕 | 几何纯度越高越突出 |
| **主角** | 战场怪物 | 不规则有机剪影 | 运动 + 有机形状在几何背景中自然突出 |
| **配角** | 空格子 | 方形最低对比度 | 低透明度、无填充、无投影 |
| **配角** | 已放置方块 | 方形中等对比度 | 静态、低饱和、无光晕 |
| **配角** | UI 框架 | 方形面板 | 屏幕边缘、色彩低调 |
| **配角** | 粒子/VFX | 微小几何碎片 | 小尺寸、低饱和、快速消散 |

**层级排序原理**：运动 > 静止。暖色 > 冷色。有机 > 几何（在几何世界中类比高）。几何纯度越高 > 几何越模糊。

## Section 4: Color System

### 4.1 主色板（Primary Palette）

| # | 名称 | Hex | 角色 | 语义 |
|---|------|-----|------|------|
| 1 | **石板灰** (Grid Stone) | `#4A6078` | 网格线、棋盘基底、中性 UI 背景 | 稳定、测量、舞台——整个游戏世界的地面 |
| 2 | **霜钢蓝** (Frost Steel) | `#5982A8` | 炮塔主色、建造期 UI 边框、方块轮廓 | 结构、工程、可靠、"玩家领地" |
| 3 | **冰川青** (Glacier Cyan) | `#34B3A8` | 冰塔主色、减速/冻结 VFX | 寒冷、控制、停滞、时间延缓 |
| 4 | **翠绿** (Verdant Green) | `#4A9E64` | 箭塔主色、精准指示器 | 精准、瞄准、单体聚焦 |
| 5 | **余烬橙** (Ember Orange) | `#D97836` | 战斗 UI 边框过渡、怪物逼近警示 | 升级、逼近的威胁、紧张攀升 |
| 6 | **猩红** (Crimson Red) | `#CF3A3A` | 突破警报、怪物血条、致命危险 | 紧急、敌人、毁灭、警报 |
| 7 | **日辉金** (Solar Gold) | `#E6C340` | 星级三角光点、波次通关确认、资源/货币 | 成就、价值、赢得的回报、精通 |

颜色 1-4 = **玩家冷色域**。颜色 5-6 = **敌人暖色域**。颜色 7（日辉金）= 唯一跨域桥梁色。
石板灰是整个系统的锚点。棋盘背景为石板灰加深至 30% 亮度（`#263040`）——呼应 "暗室中发光的沙盘地图"。
三种塔的冷色在色相环上间隔约 30-40 度。
余烬橙和猩红的接近性（~24 度差）形成连续紧张梯度：橙="注意"→ 红="行动"。

### 4.2 语义色映射

| 语义类别 | 颜色 | Hex | 备份线索 |
|---------|------|-----|---------|
| **危险 / 紧急** | 猩红 | `#CF3A3A` | 脉动动画（~2Hz）、X 形图标、屏幕边缘红光渗入 |
| **警示 / 注意** | 余烬橙 | `#D97836` | UI 边框宽度增加、波次数字跳动、路径末端高亮 |
| **安全 / 确认** | 翠绿（战斗）/ 霜钢蓝（建造）| `#4A9E64` / `#5982A8` | 勾号图标、短暂亮起（~0.5s）、无脉动 |
| **奖励 / 获得** | 日辉金 | `#E6C340` | 三角光点动画、数字上飘、音效 |
| **信息 / 中性** | 石板灰高亮变体 | `#6B8299` | 无动画、静态呈现 |
| **不可用 / 禁用** | 石板灰 40% 透明度 | `rgba(74,96,120,0.4)` | 无 hover 响应、无光晕、文字降对比度 |
| **放置有效** | 霜钢蓝 + 冷白预览 | `#5982A8` + `#D8E4F0` | 预览方块清晰边界、无光晕 |
| **放置无效** | 猩红 50% 透明度 | `rgba(207,58,58,0.5)` | 预览方块 X 形斜线填充、无光晕 |
| **怪物 / 敌方** | 暖色有机渐变 | `#CF3A3A` → `#D97836` | 有机曲线剪影、脉动动画 |

关键设计决策：
- 安全/确认颜色按阶段语境切换——建造用霜钢蓝（与建造环境一致），战斗用翠绿（在暖色紧张环境中需要"冷色安全区"）。两者同属玩家冷色域，语义统一。
- "不可用"不引入新颜色——直接在石板灰上降透明度，让禁用元素退入棋盘背景。
- 怪物不使用单一颜色——在暖色域内用有机渐变，呼应"有机曲线=混沌"。

### 4.3 建造 vs 战斗的色温规则

> **棋盘的石板灰基底在建造和战斗阶段保持完全相同的色值和透明度。变化只发生在 UI 框架、背景氛围层、和特效层。**

#### 建造阶段
- 棋盘：石板灰 100%（网格线 ~70-80% 透明度），无暖色渗入
- UI 边框：霜钢蓝，静态，无脉动
- 可交互元素：霜钢蓝高亮，冷白色预览（`#D8E4F0`）
- 背景氛围：石板灰深色变体（`#263040`），均匀无渐变
- 色温：~7000-8000K
- 唯一暖色例外：塔的星级金色光点——"已兑现的成就"

#### 战斗阶段
- 棋盘：石板灰 100%——**不变**
- UI 边框威胁梯度：远端=霜钢蓝 → 中点=余烬橙（~0.5Hz）→ 近终点<30%=猩红（~1Hz）→ 突破=急速猩红（~2Hz）
- 怪物路径：走过处留下余烬橙残影（~0.5-1秒消退），如烧红的铁轨
- 特效层：暖色高光透明度 ≤40%——不得遮挡网格线
- 背景氛围：从均匀冷色 → 边缘极暗（`#1A1F2B`），"世界向内收缩"
- 色温：棋盘内仍 ~7000K，UI 边缘 ~3000-4000K

#### 过渡动画
- 建造→战斗：UI 边框渐变 0.5-0.8 秒，缓出曲线
- 战斗→建造（胜利）：暖色快速回落 0.3-0.5 秒，日辉金确认光点亮终点

### 4.4 塔类型颜色与星级点缀

#### 塔主色（永久维度 — 与形状绑定）

| 塔 | 形状 | 主色 | Hex | 色相理由 |
|----|------|------|-----|---------|
| **炮塔** | 方形 | 霜钢蓝 | `#5982A8` | 蓝灰=钢铁、机械、工程。方形+钢色="可靠的火力" |
| **冰塔** | 圆形 | 冰川青 | `#34B3A8` | 青=冰、寒冷、液态。圆形+青色="包容的减速力场" |
| **箭塔** | 三角形 | 翠绿 | `#4A9E64` | 绿=精准（瞄准镜十字线传统）、锐利。三角形+绿色="指向性单体打击" |

内部渲染：扁平纯色填充 + 1px 深色边线（主色加深 30%）。无渐变、无纹理。

#### 星级点缀（可变维度 — 跨类型统一）

| 星级 | 金色三角数 | 点缀描述 | 动画 |
|------|----------|---------|------|
| **1 星** | 0 | 纯几何轮廓，无金色 | 静态 |
| **2 星** | 2 | 塔两侧各 1 个日辉金三角光点 | 光点微呼吸（~0.3Hz，亮度 ±10%） |
| **3 星** | 3 | 三等分各 1 个光点 + 1px 金色轮廓光晕（透明度 30%） | 光点呼吸 + 光晕微旋转（~0.5Hz） |

关键规则：
- 金色三角尺寸/颜色/间距在三种塔间完全一致——一套"星级语言"
- 星级升级不改变塔的轮廓大小、填充色、或形状
- 三角形光点延续全局三角形语义="精确/指示"

### 4.5 UI 色板延伸规则

所有 UI 颜色都是主色板 7 个颜色的亮度/饱和度变体，不引入新色相。

| UI 元素 | 来源色 | 衍生方式 | 用途 |
|---------|--------|---------|------|
| 深色面板背景 | 石板灰 | 亮度降至 20%（`#263040`） | 菜单面板、结算弹窗、暂停遮罩 |
| 浅色 UI 文字 | 石板灰 | 亮度升至 85%（`#C8D4E0`） | 主要文本、数字、标签 |
| 次级 UI 文字 | 石板灰 | 亮度升至 55%（`#7A8FA3`） | 说明文字、快捷键提示 |
| 按钮（可用） | 霜钢蓝 | 原色填充 | 建造按钮、确认按钮 |
| 按钮（悬停） | 霜钢蓝 | 亮度 +15%（`#6D99BF`） | hover 反馈 |
| 按钮（按下） | 霜钢蓝 | 亮度 -15%（`#476C8F`） | 按下反馈 |
| 资源/货币数 | 日辉金 | 原色 + 1px 暗色投影 | 金币数、宝石数 |
| 波次计数（建造） | 石板灰高亮 | `#6B8299` | 准备阶段 |
| 波次计数（战斗） | 余烬橙→猩红 | 按威胁等级过渡 | 战斗中 |

禁止事项：
- 禁止纯黑（`#000000`）或纯白（`#FFFFFF`）——所有极值都是石板灰变体
- UI 按钮禁止圆角（Section 3.3 已规定：尖角矩形）
- 战斗阶段 UI 颜色变化仅限边框和数字——面板背景始终为深色面板背景

### 4.6 色盲安全

#### 全局法则
1. **无色独裁**：游戏中没有任何信息仅通过颜色传达。每个颜色信号伴随形状/位置/动画/图标/文字中的至少一个备份线索。
2. **形状优先于颜色**：塔类型和星级的识别线索是形状——原则 2 的设计深意：形状在色盲下不受影响。
3. **动画区分状态**：同色不同状态必须有不同的动画模式——扩张 vs 收缩、静态 vs 脉动。
4. **UI 文字兜底**：所有关键状态转换都有 UI 文字提示。

#### 红绿色盲（影响约 8% 男性）
- 放置有效/无效 → 形状备份：有效=实心方块，无效=X 形斜线方块
- 波次胜利/防线突破 → 动画备份：胜利=扩张暗角，突破=脉动红光。UI 文字明确写结果
- 箭塔辨识 → 形状为主：三角形轮廓在小尺寸下可辨

#### 蓝黄色盲（影响约 0.01% 人口）
- 炮塔 vs 冰塔 → 形状为主：方形 vs 圆形
- 建造 UI vs 冰塔 VFX → 位置+形状：UI 在屏幕边缘细矩形，VFX 在棋盘内圆形扩散

## Section 5: Character Design Direction

### 5.1 玩家化身：无（上帝视角指挥官）

本游戏没有玩家角色。玩家不存在于棋盘世界中——你是俯瞰棋盘的设计者，如同建筑师俯视蓝图、将军俯视沙盘。玩家的"存在"通过以下方式间接表达：

- 光标：建造阶段的精确冷白十字或方块预览光标
- UI 交互：按钮点击、拖拽操作的即时反馈
- 选择高亮：被选中的塔/方块出现 1px 霜钢蓝轮廓

不存在任何拟人化的"指挥官之手"动画或头像。玩家是棋盘之外的存在，不进入画面。

### 5.2 塔的视觉人格

#### 炮塔（方形 · 霜钢蓝 `#5982A8`）— 可靠的哨兵

- **一句话性格**："我守在这里，你不用看第二眼。"
- **视觉态度**：沉稳、可靠、不炫耀。炮塔是玩家放下后最不需要担心的塔。
- **形状表达**：完美正方形——对称、平衡、无方向偏好。炮塔不"看"任何方向，它覆盖一切。
- **动画性格**：攻击时极微小的后坐力位移（1-2px），快速回弹。如同重炮的闷响——有力但不张扬。无旋转。

#### 冰塔（圆形 · 冰川青 `#34B3A8`）— 沉静的结界师

- **一句话性格**："它们走不快——我已经帮你拖住了。"
- **视觉态度**：冷静、从容、包容。冰塔不造成恐惧——它带来的是"被保护"的安全感。
- **形状表达**：完美圆形——无起点无终点、均匀扩散。圆 = 力场、光环、范围。
- **动画性格**：常驻微呼吸——极淡圆形力场光环（透明度 8-12%），~0.2Hz 缓慢扩张-收缩。攻击触发时光环瞬间扩散至满格（~0.3s），快速回缩。

#### 箭塔（三角形 · 翠绿 `#4A9E64`）— 锐利的狙击手

- **一句话性格**："你看到那个了吗？没了。"
- **视觉态度**：精准、锋利、毫不留情。箭塔有"方向感"和"指向性"。
- **形状表达**：完美等边三角形——有一个明确的顶点方向。三角形 = 瞄准、指向、穿刺。
- **动画性格**：攻击时极小幅度旋转（5-8°），顶点瞬间对准当前目标——如同"点头"确认击杀。攻击间隔期间微小待机旋转摇摆（±3°，~0.3Hz）。

| 特质 | 炮塔（方） | 冰塔（圆） | 箭塔（三角） |
|------|----------|----------|------------|
| 态度 | 沉稳可靠 | 从容包容 | 锐利精准 |
| 存在感 | 不动如山 | 弥漫呼吸 | 警惕扫描 |
| 攻击感 | 闷响后坐 | 波纹扩散 | 点头穿刺 |
| 旋转 | 否（全对称） | 否（塔本体不动） | 是（有方向） |

### 5.3 怪物的视觉角色分类

所有怪物遵循 100% 有机曲线法则，通过尺寸、复杂度、光晕、入场四维度区分等级。

| 特征 | 普通 | 精英 | Boss |
|------|------|------|------|
| 尺寸（vs 格子） | 60-75% | 85-95% | 100-115% |
| 剪影曲线数 | 1-2 | 3-5 | 6+ |
| 颜色数量 | 1 色 | 2 色渐变 | 多色 + 金色点 |
| 光晕透明度 | 0% | 8-12% | 18-25% |
| 入场预警 | 无 | 0.5s 光点 | 1-2s 脉动圈 |
| 动画 | 平滑蠕动 | 蠕动+附属突起摇摆 | 多频蠕动+附属突起快速摇摆 |

> 设计测试：截取战斗画面一帧，模糊 2px。精英应靠"更大的色块+微光晕"被识别；Boss 应靠"溢出格子的不规则形状+明显光晕"无法被忽略。

### 5.4 合星动画序列（~0.6-0.8 秒）

| 阶段 | 时长 | 视觉 |
|------|------|------|
| 聚合 | 0-0.25s | 两塔向彼此滑入，半透明化至 50% |
| 融合闪光 | 0.2-0.35s | 重合点爆出冷白光球（`#D8E4F0`）——遮盖形状过渡的"视觉遮罩" |
| 显形 | 0.3-0.55s | 高一级新塔先以 110% 尺寸出现，弹性缓出回弹至 100% |
| 星级确认 | 0.45-0.6s | 新增金色三角依次亮起，每个间隔 ~0.05s |
| 就位 | 0.6-0.8s | 塔恢复静态，新光点进入微呼吸循环 |

合星失败（不同塔种拖到一起）：两塔弹回原位（弹性缓出 ~0.3s），无闪光，光标短暂显示红色 X。

### 5.5 三种终结视觉

| 事件 | 碎片形状 | 碎片颜色 | 残留标记 | 情绪 |
|------|---------|---------|---------|------|
| 怪物被杀 | 有机不规则碎片 4-16 片 | 余烬橙→透明 | 淡暖色微光快速消散 | 满足 |
| 防线突破 | 无碎片——路径红色残影 | 猩红 | 路线"伤疤"残留至波次结束 | 警报 |
| 塔被摧毁 | 几何碎片（方/弧/三角） | 冷色→透明 | 塔色轮廓残影缓慢消退 | 损失 |

## Section 6: Environment Design Language

### 6.1 棋盘即世界

> 棋盘之外没有世界。玩家看到的全部空间就是棋盘 + 棋盘周围的虚空。不需要额外的世界构建。

这不是技术限制——这是设计选择。这款游戏不假装自己发生在某个虚构地点。它就是一款棋盘游戏——如同国际象棋、围棋——棋盘就是它的全部宇宙。

棋盘环境由三个视觉层构成：

| 层 | 内容 | 视觉角色 |
|----|------|---------|
| 棋盘面（表层） | 网格线、方块、塔、怪物、粒子 | 游戏内容层 |
| 棋盘底（基底层） | 石板灰底色 `#263040`、极微弱蓝图网格纹理 | 游戏世界的"地面" |
| 虚空（外围层） | 棋盘外的所有空间 | 无限感的载体 |

### 6.2 背景层：径向衰减虚空

棋盘外背景使用从棋盘边缘向外的径向渐变：

| 区域 | 颜色 | 透明度 | 感受 |
|------|------|------|------|
| 棋盘内 | `#263040` | 100% | 实体地面 |
| 边缘外 0-40px | `#1A1F2B` | 80%→20% | 过渡带 |
| 边缘外 40-120px | `#0F141A` | 20%→0% | 虚空深部 |
| 屏幕边缘 | `#0A0D12` | — | 自然融入 |

**禁止硬边框**：棋盘边缘绝不能有一条可见的边框线——棋盘的边界由网格线的终点暗示，而非由边框宣示。

战斗阶段随波次递增，虚空边缘向内微收：过渡带从 ~40px → ~30px（第 25 波后）→ ~20px（第 50 波后）。"虚空在向棋盘逼近"——极缓慢的阈下空间压缩。

### 6.3 纹理哲学：精准扁平

> 几何本身就是纹理。不需要额外的材质、噪点或手绘肌理来"丰富"画面——线条的精度、形状的纯度、色彩的克制就是视觉丰富度的来源。

| 分层 | 扁平度 | 例外 |
|------|--------|------|
| 棋盘基底 | 扁平 + 极微弱蓝图网格纹理（透明度 3-5%） | 唯一可引入微妙纹理的层 |
| 障碍方块 | 纯扁平——实色 + 1px 深色边线 + 1px 投影（15% 透明度） | 投影区分高度差 |
| 防御塔 | 纯扁平——形状 + 主色 + 1px 边线。无渐变 | 3 星金色光晕是唯一例外 |
| 怪物 | 扁平 + 有机渐变——渐变色在填充内允许 | 渐变传达有机感 |
| UI 元素 | 纯扁平。尖角矩形、实色、1px 边框 | 无渐变无阴影 |
| 粒子/VFX | 微小扁平几何碎片 | 非烟雾，是几何碎片 |

**纹理禁令**：仿材质纹理（石头/金属/木头）、噪点/颗粒/胶片颗粒、手绘笔触、多层投影/内阴影/浮雕——全部禁止。

### 6.4 视觉焦点层次

| 焦点级 | 区域 | 视觉强度 | 包含内容 |
|--------|------|---------|---------|
| F1 核心区 | 棋盘中心 ~60% 区域 | 最高对比度 | 活跃怪物路径、攻击中的塔、怪物聚集区 |
| F2 监控区 | 棋盘外围 ~40% 区域 | 中等对比度 | 空格子、闲置塔、未使用方块 |
| F3 环境区 | 棋盘外虚空 | 最低对比度 | 虚空、UI 框架、波次计数 |

F1/F2 不由固定空间划分——它们随每波战斗动态变化。怪物路径沿线自动成为 F1，路径远端自动退为 F2。棋盘亮度不衰减——衰退只通过网格线透明度、色温、信息密度三个维度。

### 6.5 "无限"的视觉表达

无限不来自空间切换，而来自时间的深度和空间的边界感缺失。

- **载体 1**：虚空的无边界性——棋盘漂浮在无边框虚空中。网格线在棋盘边缘不做截断标记。
- **载体 2**：波次计数器的仪式性——唯一持续单向增长的视觉元素。关键波次（10/25/50/100）数字短暂放大+日辉金闪烁。
- **载体 3**：虚空的渐进式压缩——每 25 波 ~10px 的极缓收缩，阈下传达"世界在变紧"。
- **载体 4**：无终点的路线隐喻——怪物从虚空来，走进虚空去。棋盘只是无限战场的一个切片。

## Section 7: UI/HUD Visual Direction

### 7.1 桌面端鼠标优先

- 左键 = 放置方块、选择塔、拖拽合星、点击按钮
- 右键 = 取消选择、移除方块、打开塔信息面板
- 无滚轮功能（棋盘完整可见，无需缩放）
- 无键盘快捷键（MVP 阶段）
- 光标：默认箭头 → 悬停可交互元素变手型 → 拖拽中变抓取
- 点击目标最小尺寸：36×36px（1080p）

### 7.2 屏幕区域划分

```
┌─────────────────────────────────────────────┐
│  顶部信息栏 48px — 波次│金币│防线│菜单       │
├─────────────────────────────────────────────┤
│               棋盘区域 (Grid Area)           │
│            20×15 网格，画面绝对焦点          │
├─────────────────────────────────────────────┤
│  底部操作栏 64px — 塔选择│方块│技能│开始     │
└─────────────────────────────────────────────┘
```

- 无侧边栏——棋盘两侧的空白区属于呼吸空间
- 弹窗/模态居中覆盖，半透明遮罩（60%），弹窗不超过画面 60%

### 7.3 HUD 元素目录（12 个）

| 元素 | 位置 | 关键颜色 | 动态行为 |
|------|------|---------|---------|
| 波次计数 | 顶部左 | 建造=石板灰高亮；战斗=余烬橙→猩红梯度 | 数字跳动 |
| 金币显示 | 顶部左 | 日辉金 + 1px 暗色投影 | 增加=数字上飘+微光；减少=短暂缩放 |
| 防线状态条 | 顶部左 | 满=霜钢蓝 → 低=猩红 | ≤30% 脉动 ~1Hz |
| 菜单按钮 | 顶部右 | 霜钢蓝，hover 提亮 15% | 0.1s 过渡 |
| 塔选择按钮 ×3 | 底部中 | 各塔主色 | 选中=金色轮廓 |
| 方块按钮 | 底部中 | 石板灰 | 选中=边框高亮 |
| 应急技能按钮 ×2 | 底部右 | 冰冻=冰川青，维修=翠绿 | 冷却=石板灰 40% + 冷却环 |
| 准备/开始按钮 | 底部右 | 建造=霜钢蓝；战斗=隐藏 | 点击=缩放回弹 |
| 合星预览 | 居中弹窗 | 深色面板 | 拖拽同星塔重叠弹出 |
| 结算面板 | 居中弹窗 | 深色面板 + 日辉金或猩红标题 | 数字逐个弹出 |
| 塔信息浮层 | 悬停塔时 | 深色面板 80% 透明度 | 0.15s 淡入 |
| 放置预览 | 跟随光标 | 有效=霜钢蓝 50%，无效=猩红 50%+X斜线 | 0ms lag，贴合格网格 |

### 7.4 字体

- 主字体：几何无衬线体（推荐 Outfit），字形骨架以圆形和直线构成
- **等宽数字刚性要求**：波次计数、金币数、伤害数字、结算统计使用等宽数字（tnum）
- 字号（1080p 基准）：结算标题 32px Bold → 波次/金币 20px Medium（等宽）→ 按钮 16px Medium → 浮层 14px → 提示 11px
- 文字投影：主要数字 1px 暗色投影
- 字符集：MVP 仅 Latin-1，预留 CJK 路径

### 7.5 图标：纯几何

- 24×24px（1080p），1.5-2px 统一线宽
- 方形/圆形/三角形/正交线构成，延续全局几何语言
- 线条端点平头，无圆头端点
- 12 个功能图标清单（金币/波次/冰冻/维修/三种塔/方块/开始/菜单/关闭/确认）

### 7.6 UI 动画规则

| 规则 | 值 |
|------|-----|
| 时长 | 全部 ≤300ms（唯一例外：胜利确认光 1000ms） |
| 缓动 | 全部 ease-out 或线性 |
| 禁止 | 弹跳/弹性/旋转入场、面板从侧边滑入、连续旋转加载、打字机效果 |
| 阶段切换 | 建造↔战斗 UI 边框颜色渐变 500-800ms |

### 7.7 UI 色彩应用

- 面板背景：顶层弹窗 `#263040` 100% → 模态遮罩 60% → 栏 90% → 浮层 80% + 1px 霜钢蓝边框
- 选中态：边框从 1px 增至 2px + 1px 日辉金外轮廓
- 战斗紧迫：UI 边框颜色渐变（Section 4.3），不增边框宽度

## Section 8: Asset Standards

### 8.1 Godot 4.6 文件格式

| 资源类型 | 格式 | 说明 |
|---------|------|------|
| 场景 | `.tscn` | 塔/怪物/方块各自独立场景，UI 屏幕各自独立场景 |

| 着色器 | `.gdshader` | Godot 着色器格式 |

### 8.2 精灵图分辨率

基准单元格：**56×56px（1080p，1x）**。2x（4K）= 112×112px。

| 资源 | 1x | 画布 | 规则 |
|------|-----|------|------|
| 网格单元格 | 56×56 | 64×64 | 石板灰 + 网格线 |
| 障碍方块 | 56×56 | 64×64 | 填满单元格，1px 深色边线 |
| 炮塔 | 48×48 | 64×64 | 格内 86%，纯方形 |
| 冰塔 | 直径 44 | 64×64 | 纯圆形 |
| 箭塔 | 内切 46×46 | 64×64 | 纯等边三角形，尖端朝上 |
| 怪物 | 最大 48×48 | 64×64 | 严格不超出 1 格 |
| 星级光点 | 8×8 | 16×16 | 日辉金小三角 |
| UI 图标 | 24×24 | 32×32 | 纯几何 |

画布为 2 的幂（64/128px），图形居中留 4-8px 透明 padding。

### 8.3 资源文件夹结构

### 8.4 纹理导入设置（Godot 4.6）

| 设置 | 值 | 理由 |
|------|-----|------|

## Section 9: Style Prohibitions

### 9.1 路线与可读性（P-01 ~ P-03）

| # | 禁止事项 | 为什么 |
|---|---------|--------|
| P-01 | 任何视觉元素遮挡或弱化路线 | 路线=首要武器。全屏滤镜/过密粒子/过大 UI 弹窗触犯此条。**无豁免可能** |
| P-02 | 网格线在战斗阶段消失或被特效覆盖 | 战斗紧张时更需要看清路线的空间位置。特效透明度 ≤40% |
| P-03 | 全屏红色滤镜传达危险 | 精准红色指向比全屏红更有效。全屏红让玩家无法看清剩余路线 |

### 9.2 形状相关（P-04 ~ P-09）

| # | 禁止事项 | 为什么 |
|---|---------|--------|
| P-04 | 塔轮廓使用混合形状 | 纯方/圆/三角在小尺寸下辨识度最高 |
| P-05 | UI 元素使用圆角 | 唯一例外：怪物血条。尖角延续刚性几何统一 |
| P-06 | 怪物精灵使用直线或尖角 | 怪物=混沌。直线模糊敌我视觉边界 |
| P-07 | 高星塔通过增大体积表现星级 | 体积变化改变空间预期。用金色三角点缀表达 |
| P-08 | 方块使用圆角/斜面/倒角 | 方块=刚性障碍。圆角暗示"可以滚/可以走" |
| P-09 | 网格线使用虚线/渐变/非 90° 交叉 | 网格=测量工具不是装饰 |

### 9.3 色彩相关（P-10 ~ P-16）

| # | 禁止事项 | 为什么 |
|---|---------|--------|
| P-10 | 纯黑 `#000000` 或纯白 `#FFFFFF` | 极值用石板灰变体：最深 `#1A1F2B`，最亮 `#D8E4F0` |
| P-11 | UI 引入 7 色板之外的新色相 | 7 色已覆盖全部语义。新色=未定义语义的歧义 |
| P-12 | 仅用颜色传达信息 | 色盲安全法则。必须有形状/位置/动画/文字备份 |
| P-13 | 建造阶段出现暖色 | 唯一例外：塔的星级金色光点 |
| P-14 | 棋盘基底在两阶段间变化色值 | 棋盘是稳定锚点 |
| P-15 | 怪物使用单一纯色 | 怪物=暖色域有机渐变，呼应有机形状语义 |
| P-16 | 塔内部使用渐变或纹理 | 塔=纯色填充+1px边线 |

### 9.4 UI 相关（P-17 ~ P-23）

| # | 禁止事项 | 为什么 |
|---|---------|--------|
| P-17 | UI 动画超过 300ms（唯一例外：胜利确认光） | UI 服务于信息，不服务于表演 |
| P-18 | 弹跳/弹性/旋转入场等装饰性缓动 | 刚性几何世界观不兼容有机动画曲线 |
| P-19 | UI 面板从屏幕外滑入 | 滑入=触屏隐喻，桌面端无功能对应 |
| P-20 | 图标使用手绘/位图/拟物风格 | 纯几何图标语言 |
| P-21 | 图标线条使用圆头端点或圆角连接 | 与 P-05 一致 |
| P-22 | 数字字体使用比例数字 | 等宽数字防抖动 |
| P-23 | 准备/开始按钮在战斗阶段显示 | 战斗无准备操作，隐藏防误触 |

### 9.5 资产规范相关（P-24 ~ P-29）

| # | 禁止事项 | 为什么 |
|---|---------|--------|
| P-24 | 精灵图使用 Linear 纹理过滤 | Nearest 保持几何边缘锐利 |
| P-25 | 使用 .svg 作为运行时精灵图源 | Godot SVG 性能不可控 |
| P-26 | 精灵图开启 Mipmaps | 2D 不需要，增加内存 |
| P-27 | 精灵图使用有损压缩 | 几何边缘对压缩伪影敏感 |
| P-28 | 精灵图实际图形触及画布边界 | 留透明 padding 防纹理溢出 |
| P-29 | UI 与游戏精灵图使用不同导入设置 | 统一管线减少配置错误 |

### 9.6 世界观一致性（P-30 ~ P-34）

| # | 禁止事项 | 为什么 |
|---|---------|--------|
| P-30 | 棋盘基底纹理出现有机形状或自然材质 | 棋盘=几何舞台，非自然环境 |
| P-31 | 怪物数量/体积超过建造元素视觉总和 | 支配层级：方形 >> 圆形 > 三角形 |
| P-32 | 特效/粒子使用有机形状 | VFX 属于玩家领地，使用几何碎片 |
| P-33 | 屏幕闪白作为伤害反馈 | 闪白遮挡路线数帧 |
| P-34 | 棋盘上叠加半透明全屏覆盖层 | 用屏幕边缘暗角代替 |

### 9.7 此列表的使用方式

- 设计审查检查清单：审核任何视觉资产/UI 布局/特效时逐条对照
- 新增禁止项：发现新的违规模式时添加，格式一致
- 争议处理：需 creative-director 批准豁免并记录原因
- **P-01 为最高优先级——无豁免可能**
